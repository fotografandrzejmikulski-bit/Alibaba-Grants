# OMEGA-X — Reviewer Questions & Answers

## Why Alibaba Cloud?

OMEGA-X addresses a concrete enterprise conversion barrier: the engineering work needed to prove migration feasibility, security, cost, and operational readiness. Alibaba Cloud is the target environment and a strategic beneficiary because successful migrations can result in recurring workloads on Alibaba Cloud.

## Why is AI necessary?

Architecture interpretation, infrastructure transformation, code generation, risk analysis, and evidence generation contain repetitive but context-heavy reasoning tasks. A coordinated AI workflow can reduce manual iteration while deterministic controls prevent language-model output from becoming uncontrolled infrastructure execution.

## What is actually built today?

The project brief identifies Alpha 0.4 with basic Terraform scanning and translation toward Alibaba Cloud equivalents in local containerized environments. The external application should not imply that cloud-hosted production deployment or the full enterprise pilot program is already complete.

## How will you measure the claimed 60% improvement?

Use paired baseline-vs-OMEGA-X measurements for comparable migration scope. Measure elapsed qualification time, engineering hours, review hours, number of generated artifacts, validation iterations, and model usage. The 60% figure remains a target until validated.

## How will you prevent hallucinated infrastructure?

Model output is treated as untrusted. Syntax/schema validation, policy evaluation, security checks, artifact hashing, bounded repair loops, and human approval gates separate generation from consequential deployment.

## How is sensitive data handled?

The platform is designed to minimize model context, redact secrets, apply data-classification rules, restrict cross-region transfers, and keep customer access scoped. The application should state the exact deployed controls once they are implemented and tested.

## Does OMEGA-X guarantee GDPR compliance?

No. It provides technical controls that can support GDPR and data-residency requirements. The customer remains responsible for legal determination and compliance governance.

## Why request the maximum program amount?

The planning model assumes a controlled 15-pilot enterprise program with costs for compute, data/context services, networking/security, validation, and pilot execution. The application asks for the maximum available support only to the extent permitted and approved under current program terms.

## Will all 15 pilots become production customers?

No outcome is guaranteed. Production conversion is a KPI to be measured. This is preferable to presenting an unsupported conversion claim.

## Why Model Studio / Qwen?

The proposed architecture is designed to evaluate Alibaba Cloud's native model platform and Qwen-family capabilities for infrastructure reasoning, code generation, security analysis, and workflow orchestration. Final model selection is performance- and cost-driven and will be confirmed during implementation.
