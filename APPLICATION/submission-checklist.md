# Alibaba Cloud AI Catalyst — Submission Checklist

## Identity and account

- [ ] Legal applicant name verified.
- [ ] Company website verified and publicly reachable.
- [ ] Headquarters / registered address verified.
- [ ] Alibaba Cloud ID obtained from Account Center.
- [ ] Business account status verified where required.
- [ ] Contact name, title, email, and phone verified.

## Application form

- [ ] AI is genuinely a core technology of the primary solution.
- [ ] AI use case answer is within the application's character limit.
- [ ] Monthly AI-resource spend band reflects the applicant's real forecast.
- [ ] Company deck URL works without requiring internal permissions.
- [ ] VC referral field is completed only when factually applicable.

## Product evidence

- [ ] Alpha 0.4 capability is reproducible.
- [ ] Terraform fixture included.
- [ ] Generated target artifact included.
- [ ] Validation result included.
- [ ] Known limitations documented.
- [ ] Planned Alibaba Cloud validation clearly separated from current capability.

## Technical readiness

- [ ] Alibaba Cloud region selected after checking service availability.
- [ ] Model Studio access validated.
- [ ] Model/API configuration documented.
- [ ] IAM/RAM permissions reviewed.
- [ ] Logging and budget controls enabled.
- [ ] Runaway-agent protection tested.
- [ ] Human approval gates enforced for consequential operations.

## Grant economics

- [ ] Requested amount described as subject to program approval.
- [ ] No unsupported claim of a guaranteed tier.
- [ ] Cloud credit budget linked to measurable workloads.
- [ ] Model consumption budget distinguished from compute/storage/network costs.
- [ ] Pilot-level cost attribution implemented.

## Claims review

Replace or qualify any statement that implies:

- guaranteed ROI,
- guaranteed customer conversion,
- guaranteed production workload migration,
- guaranteed GPU SKU/region availability,
- automatic legal/regulatory compliance,
- contractual entitlement to a public maximum grant amount.
