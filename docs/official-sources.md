# Official Alibaba Cloud Sources

Verified on 2026-09-05.

## AI Catalyst application

Alibaba Cloud's public AI Catalyst application form asks for company identity, website, HQ, Alibaba Cloud ID, whether AI is core technology, AI use case, estimated monthly AI-resource spend, deck URL, contact details, and optional VC referral.

Source: https://survey.alibabacloud.com/uone/sg/survey/Ki6nZZ5hr

## Model Studio Token Plan

Alibaba Cloud's current Token Plan documentation describes a Credits-based subscription model and states that Token Plan is currently available in Singapore. It also documents Team Edition and Individual Edition and multiple AI coding/agent tools.

Source: https://www.alibabacloud.com/help/en/model-studio/token-plan-overview

## Model inference pricing

Alibaba Cloud documents pay-as-you-go Model Studio inference and separate pricing behavior for context caching. Pricing depends on the selected model and usage pattern.

Source: https://www.alibabacloud.com/help/en/model-studio/model-pricing

## Model Studio savings plans

Alibaba Cloud documents Savings Plans, Resource Plans, and Token Plan as distinct mechanisms with different billing models.

Source: https://www.alibabacloud.com/help/en/model-studio/savings-plan-and-resource-package

## Marketplace technology partner

Alibaba Cloud documents a Technology Partner onboarding process and separate Marketplace vendor application requirements.

Sources:
- https://www.alibabacloud.com/help/en/marketplace/tech-partner-onboarding-process
- https://www.alibabacloud.com/help/en/marketplace/account-registration-and-apply-to-become-technology-partner

## Program maximums

Public Alibaba Cloud materials reviewed for this package describe AI Catalyst support of up to USD 120,000 in cloud credits and up to 2 billion free Model Studio tokens. The application package deliberately treats these as public maximum/program-level figures rather than guaranteed individual entitlements.

Before submission, re-check the then-current program terms and any approval email or agreement for the exact allocation, duration, eligible services, region, and expiration.
